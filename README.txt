SOCIALS COMMAND CENTER — MOBILE APP

What's included
- index.html: complete mobile-first app
- manifest.webmanifest: installable app metadata
- sw.js: service worker for offline app shell caching
- icon.svg: app icon

Features
- All 65 participants from the roster, including Tharun (#64) and Yuvanthikaa (#65)
- Tap PAID/UNPAID and COMING/ABSENT
- Automatic local saving in the browser on the same device
- Live payment and attendance progress bars
- Search and filters
- CSV backup and restore
- Installable as a PWA when served over HTTPS

IMPORTANT: For a true home-screen app experience, host these files on an HTTPS static host (for example GitHub Pages or Netlify), then open that URL on your phone and choose "Add to Home Screen" / "Install app". Service workers and PWA installation do not work reliably by opening index.html directly as a local file.

Data/privacy
Roster status is stored locally in the browser on that device. It is not automatically synced across phones or browsers. Use Backup CSV regularly. Clearing browser site data may erase saved ticks.
